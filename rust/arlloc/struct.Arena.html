Обертка над C-аллокатором арены.

§Ограничения

Метод alloc поддерживает только типы, реализующие типаж Copy. Аллокатор арены не выполняет вызов деструкторов (Drop) для размещенных данных.

§Параметры
  • initial_size — размер первого блока памяти в байтах (должен быть > 0).
  • subsequent_size — размер последующих блоков памяти в байтах (должен быть > 0).
§Возвращаемое значение

Возвращает Some(Arena) при успешном выделении памяти или None в случае ошибки (OOM).

Source

pub fn alloc<T>(&self, value: T) -> Option<&T>

Выделяет память в арене и размещает в ней переданное значение.

§Параметры
  • value — значение для размещения. Тип T обязан реализовывать типаж Copy.
§Возвращаемое значение

Возвращает Some(&mut T) с изменяемой ссылкой на размещенное значение, время жизни которой привязано к времени жизни самой арены ('a). Возвращает None в случае исчерпания памяти или невалидных параметров.

§Гарантии безопасности

Функция является безопасной (safe), так как внутренне гарантирует корректное вычисление размера и выравнивания через std::mem::size_of и std::mem::align_of.

Source

pub fn reset(&self)

Сбрасывает арену в начальное состояние.

§Внимание

Все ссылки, полученные ранее через метод alloc, становятся невалидными. Использование таких ссылок после вызова reset приведет к неопределенному поведению (Undefined Behavior).
