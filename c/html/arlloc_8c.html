Выделяет непрерывный блок памяти внутри арены.

Аргументы
arenaУказатель на аллокатор. Не должен быть NULL.
sizeРазмер выделяемой памяти в байтах. При size == 0 возвращает NULL.
alignmentТребуемое выравнивание адреса в байтах. Обязано быть степенью двойки (1, 2, 4, 8, 16, ...).
Возвращает
Указатель на выделенную память, адрес которого кратен alignment, или NULL при ошибке (OOM, невалидное выравнивание, size == 0).

◆ arena_reset()

void arena_reset ( arena_t *  arena)

Сбрасывает арену в начальное состояние для повторного использования без возврата памяти ОС.

Аргументы
arenaУказатель на аллокатор.

Освобождает все блоки, кроме первого, и обнуляет счетчик использованной памяти в первом блоке. Все ранее полученные указатели на данные в этой арене становятся невалидными.
