# Arena Memory Allocator (C)

## Описание

Данный проект представляет собой реализацию **Arena Memory Allocator** (линейного аллокатора памяти) на языке Си. Аллокатор использует стратегию последовательного выделения (bump-pointer allocation) из предварительно выделенных непрерывных блоков памяти с динамическим связыванием блоков при исчерпании емкости.

Библиотека спроектирована с учетом жестких требований к безопасности и предсказуемости поведения при использовании через Foreign Function Interface (FFI), в частности, для интеграции с языком Rust.

---

## Принцип работы

1. **Линейное выделение (Bump-Pointer):** При запросе памяти аллокатор не ищет свободные фрагменты. Он просто сдвигает указатель конца использованной памяти (offset) вперед на запрошенный размер. Это обеспечивает константное время выделения $O(1)$ и отсутствие внешней фрагментации.
2. **Динамическое связывание блоков:** Если в текущем блоке недостаточно места, аллокатор запрашивает у операционной системы новый блок памяти (через `malloc`), добавляет его в связный список и продолжает выделение в нем.
3. **Пакетное освобождение:** Индивидуальное освобождение памяти (`free` для конкретного указателя) не поддерживается. Освобождение происходит либо полным уничтожением аллокатора (`arena_destroy`), либо сбросом логического состояния (`arena_reset`), который освобождает все блоки, кроме первого.
4. **Строгое выравнивание (Alignment):** Аллокатор гарантирует, что возвращаемый указатель будет строго выровнен по запрошенной границе. Вычисление выравнивания производится от абсолютного адреса, что критически важно для корректной работы с типами, требующими выравнивания больше, чем `max_align_t` (например, SIMD-типы или специфичные структуры Rust).

---

## Архитектурные решения и совместимость с FFI

При разработке были учтены следующие ограничения и требования для безопасного пересечения границы FFI:

* **Непрозрачные указатели (Opaque Pointers):** Структура `arena_t` скрыта в файле реализации. Внешний API оперирует только указателями `arena_t*`. Это предотвращает копирование структуры по значению и гарантирует инкапсуляцию.
* **Отсутствие потокобезопасности (Thread-Unsafe):** Внутренние структуры не содержат мьютексов или атомарных операций. Это сделано намеренно, чтобы избежать накладных расходов на системном уровне. Синхронизация (например, `Arc<Mutex<Arena>>` или thread-local storage) должна реализовываться на стороне вызывающего кода (в Rust).
* **Обработка ошибок:** Функции не используют `errno` и не генерируют исключения. При ошибках (OOM, невалидные аргументы) функции возвращают `NULL`. Это позволяет вызывающему коду явно маппить результаты в `Option` или `Result`.
* **Защита от NULL:** Все функции, принимающие указатель на арену, проверяют его на `NULL` и завершают работу без падения (no-op), что предотвращает segfault при некорректном использовании из небезопасного (unsafe) кода.

## Справочник API

### Типы данных

```c
// Непрозрачный handle аллокатора
typedef struct arena_t arena_t;

// Структура статистики
typedef struct arena_stats_t {
    size_t total_allocated_bytes; // Память, фактически запрошенная у ОС (включая заголовки блоков)
    size_t total_used_bytes;      // Память, выделенная пользователю (с учетом padding для выравнивания)
    size_t block_count;           // Количество активных блоков в связном списке
} arena_stats_t;
```

### Функции

#### `arena_create`
```c
arena_t* arena_create(size_t initial_block_size, size_t subsequent_block_size);
```
* **Назначение:** Инициализирует арену и выделяет первый блок памяти.
* **Параметры:**
  * `initial_block_size` — размер первого блока в байтах. Должен быть $> 0$.
  * `subsequent_block_size` — размер всех последующих блоков в байтах. Должен быть $> 0$.
* **Возвращает:** Указатель на `arena_t` или `NULL` при ошибке выделения памяти (OOM) или если переданы нулевые размеры.

#### `arena_destroy`
```c
void arena_destroy(arena_t* arena);
```
* **Назначение:** Полностью освобождает всю память, связанную с аллокатором, возвращая её в ОС.
* **Параметры:** `arena` — указатель на аллокатор. Если передан `NULL`, функция ничего не делает.
* **Примечание:** После вызова использование указателя `arena` приводит к неопределенному поведению (UB).

#### `arena_alloc`
```c
void* arena_alloc(arena_t* arena, size_t size, size_t alignment);
```
* **Назначение:** Выделяет непрерывный блок памяти.
* **Параметры:**
  * `arena` — указатель на аллокатор. Не должен быть `NULL`.
  * `size` — размер выделяемой памяти в байтах. Если `size == 0`, возвращает `NULL`.
  * `alignment` — требуемое выравнивание в байтах. **Обязано быть степенью двойки** (1, 2, 4, 8, 16, 32...).
* **Возвращает:** Указатель на выделенную память, адрес которого кратен `alignment`, или `NULL` при ошибке (OOM, невалидный `alignment`, `size == 0`).

#### `arena_reset`
```c
void arena_reset(arena_t* arena);
```
* **Назначение:** Сбрасывает арену в начальное состояние для повторного использования.
* **Поведение:** Освобождает все блоки, кроме первого (чтобы избежать лишних системных вызовов `malloc`/`free` при следующем использовании), и сбрасывает счетчик использованной памяти в первом блоке в 0.

#### `arena_get_stats`
```c
void arena_get_stats(const arena_t* arena, arena_stats_t* stats);
```
* **Назначение:** Заполняет структуру `stats` агрегированной статистикой текущего состояния арены.
* **Параметры:** Оба указателя не должны быть `NULL`.

## Пример использования (C)

```c
#include "arena.h"
#include <stdio.h>
#include <stdint.h>

int main() {
    // 1. Создание арены: первый блок 4096 байт, последующие по 8192 байта
    arena_t* arena = arena_create(4096, 8192);
    if (!arena) {
        fprintf(stderr, "Failed to create arena\n");
        return 1;
    }

    // 2. Выделение памяти с разным выравниванием
    void* ptr1 = arena_alloc(arena, 100, 8);   // Выравнивание по 8 байт
    void* ptr2 = arena_alloc(arena, 256, 16);  // Выравнивание по 16 байт (например, для SSE)
    void* ptr3 = arena_alloc(arena, 64, 64);   // Строгое выравнивание по 64 байту (например, для AVX-512 / кэш-линий)

    if (!ptr1 || !ptr2 || !ptr3) {
        fprintf(stderr, "Allocation failed\n");
        arena_destroy(arena);
        return 1;
    }

    // Проверка корректности выравнивания
    printf("ptr1 aligned to 8: %s\n",  ((uintptr_t)ptr1 % 8 == 0)  ? "Yes" : "No");
    printf("ptr2 aligned to 16: %s\n", ((uintptr_t)ptr2 % 16 == 0) ? "Yes" : "No");
    printf("ptr3 aligned to 64: %s\n", ((uintptr_t)ptr3 % 64 == 0) ? "Yes" : "No");

    // 3. Получение статистики
    arena_stats_t stats;
    arena_get_stats(arena, &stats);
    printf("Allocated from OS: %zu bytes\n", stats.total_allocated_bytes);
    printf("Used by user: %zu bytes\n", stats.total_used_bytes);
    printf("Blocks count: %zu\n", stats.block_count);

    // 4. Сброс арены (память очищается, но первый блок остается)
    arena_reset(arena);
    
    arena_get_stats(arena, &stats);
    printf("After reset - Used by user: %zu bytes\n", stats.total_used_bytes);

    // 5. Уничтожение арены
    arena_destroy(arena);

    return 0;
}
```
